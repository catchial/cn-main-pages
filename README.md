# cn-main-pages

## 项目简介

本仓库用于归档和发布多个独立 HTML 页面。这些页面可能涉及不同主题、工具或信息展示，每个页面均为独立文件，无需额外后端支持。

仓库主要功能是作为静态页面的托管与索引，方便通过 GitHub Pages 等平台直接访问。

## 目录说明

```
cn-main-pages/
├── index.html          # 主页入口，提供页面导航
├── pages/              # 存放所有独立 HTML 页面
│   ├── page-001.html
│   ├── page-002.html
│   └── ...
└── assets/             # 公共资源（样式、脚本、图片等）
    ├── css/
    ├── js/
    └── images/
```

- `index.html`：仓库的默认起始页，通常包含页面列表或简要说明。
- `pages/`：每个子文件对应一个独立 HTML 页面，命名尽量简洁。
- `assets/`：存放页面间共享的资源文件，以减少重复。

## 页面归档说明

归档的页面满足以下特点：

- **独立完整**：每个 HTML 文件包含所需样式与脚本，不依赖外部库（除非在仓库内统一引用）。
- **轻量开放**：页面体积较小，便于快速加载与查看。
- **分类明确**：页面根据内容主题或功能放置在 `pages/` 目录下，文件名可反映其用途。

新添加的页面请遵循上述结构，并将入口链接更新至 `index.html` 中。

## 维护说明

- 欢迎提交 Issue 或 Pull Request 来修正错误、改进页面或添加新内容。
- 新增页面时，请确保：
  - 文件保存在 `pages/` 目录下。
  - 页面标题与内容清晰，无恶意代码或外部非法引用。
  - 在 `index.html` 中添加对应链接（可选）。
- 本仓库不承担页面内容的法律责任，但会尽力保持内容合规与稳定。
